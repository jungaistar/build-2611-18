# build-2611-18 · 굴착기 인양력 비교 · 시각화

생성형 AI 업무자동화 전문가과정 2차수 · 프로젝트 18 · 기획 조민규

자사 · 경쟁사 굴착기 인양력 표준 CSV(19열)를 올리면 옵션별로 걸러 전방 · 측방 인양력을 2D · 3D 로 비교하고, 기준 모델 대비 차이(%)와 엑셀 자료를 만듭니다.
기획자가 Python(Streamlit)으로 만든 V6 프로그램을 설치 없이 쓰는 웹 판으로 옮긴 것입니다.

- 사이트: https://build-2611-18.jobability.co.kr/
- 파일은 서버로 올라가지 않습니다. 읽기와 계산은 브라우저 안에서만 합니다.

| 화면 | 하는 일 |
|---|---|
| 1. 데이터 | 표준 CSV · 엑셀 올리기, 예제, 표준 양식 내려받기 |
| 2. 비교 조건 | 제조사 · 모델 · 블레이드 · 붐/암 · 캐빈 · 슈 · CW 거르기, 곡선 표시 · 색 · 기준 모델, 높이 |
| 3. 2D 비교 | 고른 높이에서 반경에 따른 전방 · 측방 인양력 곡선 |
| 4. 기준 대비 차이 | 지정 반경의 인양력과 차이(%), 사이 반경은 추정 표시, 엑셀 · CSV · 인쇄 |
| 5. 3D 비교 | 반경 × 높이 × 인양력, 끌어서 회전 |
| 6. AI 자동정리 | AI 가 읽은 JSON 을 검증해 표준 CSV 로 변환 |

## 구조

- `js/lift.js` — 계산 엔진(읽기 · 표준화 · 거르기 · 곡선 · 보간 · 비교 · JSON 변환 · 엑셀 시트). 화면 없이 `node` 로 불러 쓸 수 있습니다.
- `js/app.js` — 화면(그리기만). `js/prompt.js` — 이미지 분석 지침(기획자 V6 의 지침 그대로).
- `test/logic.test.js`(계산 규칙) · `test/smoke.browser.js`(화면, playwright 필요)

```sh
node test/logic.test.js
node test/smoke.browser.js
```
